You can now manage review findings. `forge findings` shows every finding of a repository and marks them fixed, dismissed, reopened, to file or a duplicate, with tags (ui, tests, infra, backend, docs by default, or your own), notes and edits. forge-ui's Findings tab does the same on selected rows and files the selected ones as issues, and its Memories tab can add and edit learnings (`forge memory add` / `edit`). An optional triage agent, run on a model you name, proposes duplicates, fixes, tags, issues and forge plans for related findings; nothing changes until you approve a proposal.
