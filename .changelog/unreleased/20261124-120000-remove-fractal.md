Fractal, the optional execution backend, is removed: `forge fractal`, `--fractal`, `--no-fractal`, every `--fractal-…` flag, the solo `--dwarf-low|medium|high` pools that routed its child tasks, its installer and its forge-ui endpoints. Each removed flag and command exits 2 with one line that says so. Runs made with Fractal stay readable in `forge runs` and forge-ui, but `run`, `retry` and `forge handoff resume` refuse them; start a new run for the work that is left. `forge du` shows what the old runtime left on disk. Splitting a task into subtasks is now part of forge itself (#154).
