A run from a linked git worktree whose `.forge/` is not tracked now keeps its project memory in the main checkout's `.forge/`, so `git worktree remove` can no longer delete its learnings without a word. Every reader agrees (`inject`, `forge memory show/learnings/forget/add/edit`, the decision-model gates, the run dataset), the end-of-run line names the folder, and `forge memory where <repo>` prints it. A worktree that already kept a ledger of its own has its rows moved to the main checkout's once, its files renamed `*.merged`. A tracked `.forge/` or `FORGE_MEMORY_PER_CHECKOUT=1` keeps memory per checkout (#159).
