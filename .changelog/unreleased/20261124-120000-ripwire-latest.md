Forge now installs the latest Ripwire release instead of the pinned 0.4.0, and works with Ripwire 0.6 and later (an older binary is skipped with a note saying how to update). `forge ripwire status`, `forge ripwire install` and `forge ripwire update` show, install and update it; `update` only ever replaces the Ripwire forge installed in `~/.local/bin`. When a run ends and a newer Ripwire is out, forge says so at most once a day and, on a terminal, offers to update it right away. It stays quiet in CI, offline, and with `FORGE_RIPWIRE=off` or `FORGE_UPDATE_CHECK=off`.
