`forge control steer <plan> <task> "text" --now` sends a message to a task's running claude or openclaude implementer, which takes it in at its next tool call without stopping. Those implementers now start with stream-json input (`--input-format stream-json --replay-user-messages`) fed by forge, and forge ends them a few seconds after their final result (`FORGE_LIVE_GRACE`, default 10) when no background task is open. `--now` is refused when the task has no live implementer, and a message that arrives after the final result waits for the next attempt. forge-ui adds *Send now* beside *Queue message* while the implementer runs live, and shows each message in the conversation where it landed. `control.log` records `steer-sent`, the dataset marks the message `mode: live`, and `FORGE_LIVE_STEER=off` turns it off (#252).
