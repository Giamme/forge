Forge can now show a run live in a local web page. At the start of each new run `/forge` asks "Open forge-ui to watch this run? [y/N]"; answer yes (or pass `--ui`) and forge prints a `forge-ui:` link to the tasks, statuses, models, attempts and reviewer verdicts of a decomposed or solo run, and opens it in your browser. `--no-ui` skips the question. All runs share one local server that stops itself after four idle hours, and `forge ui open|status|stop` manages it by hand; `FORGE_UI=off` disables it everywhere. A UI that cannot start never fails the run. The page has no login, so any program on your machine can read the prompts and diffs it shows. Solo runs now also record `status`, `attempts.tsv`, `dwarf.spec` and `qa.spec`.
