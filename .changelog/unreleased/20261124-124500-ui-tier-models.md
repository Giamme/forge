forge-ui can set the implementer and reviewer for each task difficulty (low, medium, high) from a plan's inspector, for the tasks that have not started yet: one model or a pool separated by commas, as `--dwarf-low` and the other tier flags take them. From the terminal it is `forge control models PLAN low --dwarf haiku:xhigh,sonnet --qa opus`. Started tasks keep their model. Every model spec in the controls, a pin included, now shows the model it runs (for example `astra:xhigh runs gpt-6.2-astra on codex`), also while you type it.
