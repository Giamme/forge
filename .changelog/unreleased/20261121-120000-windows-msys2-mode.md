Added Windows MSYS2 mode, an opt-in alternative to native mode: forge runs inside MSYS2, where process groups, signals, file locks and symlinks behave as on Linux. Set `FORGE_WIN_MODE=msys2` and start forge from Git Bash as usual, or start it from an MSYS2 shell. Setup and limits are in [Install](docs/install.md#windows-msys2-mode).
