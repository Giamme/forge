From the terminal

Everything forge-ui shows, you can also get in a terminal: follow runs live, get notified, list them, rerun a plan on another model and compare.

Follow runs live

forge watch                      # this repo's runs, new ones too
forge watch "$PLAN"              # one run, until it ends
forge watch --all --until-done   # every repo; stop once nothing is running

Every task status change prints a line. A run finishing or failing, a task newly failing and a final review's verdict also raise a desktop notification and can run a command: --exec CMD, or an executable .forge/on-finish in the repo. forge runs that hook only if it's yours, untracked by git and not writable by others, so a cloned repo can't run code on you.

List runs

forge runs                 # this repo's recent runs, newest first
forge runs --all --json    # every repo, as JSON

Each line has the run id, its kind, age, task states, verification and final review, and the goal: the same summaries forge-ui shows.

Would another model have done better?

forge runs rerun "$PLAN" --dwarf opus:high     # set up the same plan on another builder; spends nothing
forge runs rerun "$PLAN" --dwarf opus:high --run --yes
forge runs compare "$PLAN" "$PLAN-opus-high"   # side by side, per task

A rerun starts from the same commit as the original, with the same tasks and prompts, and never merges. It prints what the original spent and a forecast before you start it. One pair of runs is one sample: read it as what happened, not as which model is better.

File leftover findings as issues

./forge issues "$PLAN"                         # drafts: titles, severity, already filed
./forge issues "$PLAN" --include-plausible --apply --label bug

Each issue gets the finding, its severity, the task, the reviewer and a link to the code at the merged commit. A hidden fingerprint keeps a finding from being filed twice. Where the gh-proman skill is set up, issues land on the team's project board.

Write the pull request

forge pr                            # the newest finished run, on stdout
forge pr --create --base main       # a draft PR for its integration branch

See Merge and verification for what goes in it.
