What's coming

forge is developed in the open, mostly with forge itself. This is what's planned next and what recent releases brought. Plans change; the issue tracker is the source of truth.

Planned

Long-running plans
Plans that keep growing over days: verification runs the lanes committed on the integration branch, adopt remembers earlier rounds, integrate accepts a tree dirty only with forge's own memory, and memory written in a linked worktree is kept. #151 #155 #156 #159
Decomposition at every level
Goal to plans to tasks to subtasks with the same rules throughout, native to forge. Each split is a recorded decision within depth and size limits you approve up front, and forge-ui shows the whole tree. #153. It replaces the optional Fractal runtime, which will be removed. #154
Steering a live dwarf
An investigation into prompting a running dwarf from forge-ui, harness by harness. #134
